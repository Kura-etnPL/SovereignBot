# SovereignBot V4.1 / S2 / S3 Acceptance Baseline

Date: 2026-08-30

This document records the accepted baseline after the V4.1 vertical slice, real-Windows S2 acceptance, and S3 repository-governance hardening. It is intentionally limited to verified facts and does not begin V4.2.

## English

### Accepted product baseline

- V4 development identity remains `4.0.0-dev`.
- V4.1 persistent Jobs, Chief of Staff supervision, and Attention / `needs_attention` behavior are accepted.
- The blocking V4.1 Desktop gate covers Jobs/Chief/Attention behavior, restart hydration, pump isolation, depth/child caps, zh-CN switching, and root-scroll invariants.
- Real Windows S2 acceptance passed on current-main Desktop behavior, packaged smoke, and installed-app validation using isolated test data and fake providers.
- Sovereign Local Control is accepted as dedicated SovereignBot validation infrastructure. The control channel is project-isolated and fail-closed.
- No metered model API was introduced for acceptance.

### Governance baseline

- `main` is protected.
- Changes must go through pull requests.
- Required stable checks are:
  - `ci-gate`
  - `desktop-gate`
  - `rc-soak-gate`
- Required checks use strict up-to-date enforcement.
- Administrators are included in protection enforcement.
- Force pushes and branch deletion are disabled.
- Conversation resolution is required before merge.
- No human approval count is required; automated gates are the blocking merge policy.

### Closeout references

- V4.1 implementation: PR #91.
- Local-control bootstrap/hardening: PRs #77, #96, #97, #98.
- Stable merge gates: PR #99.
- Local-control tracking issue #76 is completed.
- Master V3→V4 track remains #69.
- V4.2 Routines remains tracked by #92 and is intentionally frozen at this baseline.

### Non-goals of this baseline

This acceptance record does **not**:

- declare stable V4 release identity;
- begin V4.2 Routines;
- begin V4.3 or later work;
- authorize weaker CI, alternate project control channels, or metered-API substitutions.

## 中文

### 已验收产品基线

- V4 开发版本继续保持 `4.0.0-dev`。
- V4.1 的持久化 Jobs、Chief of Staff 监督以及 Attention / `needs_attention` 行为已经通过验收。
- 阻塞式 V4.1 Desktop Gate 覆盖 Jobs/Chief/Attention 行为、重启恢复、任务泵隔离、深度/子任务上限、中英文切换以及根页面滚动不变量。
- S2 真实 Windows 验收已通过：包括当前 `main` 的 Desktop 行为、打包后 smoke、已安装应用验证；测试使用隔离数据与 fake providers。
- Sovereign Local Control 已作为 SovereignBot 专用、严格项目隔离、fail-closed 的真实机器验收基础设施通过验收。
- 验收过程中没有引入按量计费模型 API。

### 仓库治理基线

- `main` 已启用保护。
- 所有变更必须通过 Pull Request。
- 强制稳定 Gate 为：
  - `ci-gate`
  - `desktop-gate`
  - `rc-soak-gate`
- 强制检查要求分支与最新 base 保持同步。
- 管理员同样受保护规则约束。
- 禁止 force push，禁止删除 `main`。
- 合并前必须解决未完成的对话线程。
- 不强制额外人工 reviewer；自动化 Gate 是阻塞式合并标准。

### 收口引用

- V4.1 实现：PR #91。
- Local Control 启动与加固：PR #77、#96、#97、#98。
- 稳定合并 Gate：PR #99。
- Local Control 跟踪 Issue #76 已完成关闭。
- V3→V4 主追踪继续使用 #69。
- V4.2 Routines 继续由 #92 跟踪，并在本基线下保持冻结。

### 本基线不代表

本验收记录**不代表**：

- 发布稳定版 V4；
- 开始 V4.2 Routines；
- 开始 V4.3 或后续功能；
- 允许降低 CI 标准、跨项目复用控制通道，或用按量 API 替代既有路径。
