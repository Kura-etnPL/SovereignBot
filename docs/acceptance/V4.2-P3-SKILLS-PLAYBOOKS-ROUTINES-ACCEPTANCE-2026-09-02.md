## 验收范围

- Skill：Manual / Taught / Imported 统一为同一 Skill Store；Teach Once 经过 drafted → manual confirmation → governed Computer test → save；支持编辑、导入导出、复制、归档恢复、Team/Coworker 分配和 Create Routine。
- Skill 数据保持 `inputs / steps / expectedOutput / validators / requestedCapabilities` 字段；`requestedCapabilities` 仅为请求，不授予权限。路径、坐标、凭据、session/provider/runtime handle 等敏感或运行时字段被拒绝持久化。
- Playbook：沿用 TeamService 的声明式方法库，支持创建、编辑、查看、复制、导入导出、归档恢复及 Team/Channel 分配；步骤是推荐的 Coworker 顺序，不是 DAG 或拥有者状态机。现有 handoff 语义继续支持 skip/reorder、specialist 和 review。
- Routine：沿用 `RoutineController → JobController → Chief Loop / Governor / Computer / Apps`，支持 one-time、hourly、daily、weekly、custom interval、模板、Run Now、history、pause/resume/retry、Attention、archive/restore 和 Event trigger。Team / Project / Coworker / trusted workspace 绑定在创建和 Job 执行时 fail closed。

## 设计边界

Imported/Taught 内容始终是 untrusted product data；它不能选择工具、授予 capability、绕过 Governor 或直接执行 Computer/Apps。真实 retest 与 Routine run 都只创建普通 governed Job；Job 的当前 Coworker、Team、Project、workspace scope 和 Attention 状态由现有运行时再次校验。

保留现有 SkillStore 在未注入运行时 runner 时的 deterministic declarative retest 兼容行为；桌面生产装配会注入同一 JobController 的 governed retest runner。没有新增调度器、执行器或 authority plane。
