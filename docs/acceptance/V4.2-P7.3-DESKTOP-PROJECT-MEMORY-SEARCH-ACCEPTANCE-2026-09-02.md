## Delivered behavior

- Project memory is scoped only by a trusted canonical `project_<16 hex>` Project ID. Team IDs can no longer masquerade as Project owners, and cross-scope source writes fail closed.
- Project cards expose a safe memory summary and a direct Memory entry point. Project archive/restore and existing workspace association remain durable and restart-safe.
- Memory has a first-class local page with Coworker, Team, and Project owner selection, active/forgotten filtering, bounded text search, pin/edit/forget/delete actions, safe source trace navigation, and pending suggestion approve/reject actions.
- Memory provenance exposes only opaque source IDs and allowlisted navigation targets for conversations, artifacts, jobs, and corrections. Paths, URLs, credentials, provider continuity, and authority material remain absent from public projections.
- Search builds a bounded in-memory derived index from the existing Project, Team, Conversation, Coworker, Artifact, Skill, Playbook, Routine, Job, Computer History, and Memory projections. It rebuilds on restart/first query and invalidates after relevant local mutations, with generation protection against stale rebuild publication.
- Search/Palette supports Memory, Jobs, and Computer History in addition to the existing product surfaces, with Active/Archived/All status filtering, archived Project scope selection, Project filtering, bounded results, and safe deep links.
- The index is local conventional text search; it does not claim semantic/FTS search, sync, retention policy, or cross-device memory.
