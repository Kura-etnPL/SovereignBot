## Delivered slice

The existing Playbook library now supports an optional, backward-compatible semantic layer:

- ordered bounded `stages` with human-readable instructions, expected stage output, and advisory Coworker role/Skill recommendations;
- ordered bounded `reviewPoints` with human-readable review guidance and advisory recommendations;
- reusable expected output plus recommended Coworker roles and opaque Skill identifiers;
- structured plan viewing in the existing Playbook page and JSON-based create/edit entry in the existing editor flow.

The existing `steps` contract remains intact. Semantics are declarative fields only: they do not schedule work, invoke tools or Apps, grant Skills/capabilities, select Governor/provider accounts, create a second executor, or introduce a DAG/workflow engine. Team and Channel assignment still uses the existing Product Surface and TeamService stores and IPC path. Import/export, duplicate, archive/restore, Team Pack transfer, and restart preserve the safe fields; unknown authority/session/credential/path/provider-account fields are rejected.
