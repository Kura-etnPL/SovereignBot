## Delivered slice

The desktop Projects page now contains a first-class Project Command Center. A selected Project renders one bounded, read-only-safe workbench with the canonical related Teams, Channels, Coworkers, Files, Artifacts, Skills, Playbooks, Routines, Triggers, Memory, and Connected Apps. The Project switcher only selects the workbench; it does not jump to the first conversation.

The main-process Project service reuses the existing workspace, Team, Coworker, Conversation, Artifact, Skill, Playbook, Routine, Trigger, Memory, and Connected Apps stores/services. Public contents are bounded to 50 items per group with totals and truncation flags, use opaque identifiers and human labels/status/summary, and omit workspace paths, provider/session details, tokens, capabilities, grants, and raw authority. Associations are derived from the trusted Project workspace/team/coworker/conversation relations. Unavailable workspaces remain visible as inspectable, empty, read-only Project cards; mutation paths fail closed. Archived Projects remain inspectable and labeled while open and memory mutation stay disabled until restore.
