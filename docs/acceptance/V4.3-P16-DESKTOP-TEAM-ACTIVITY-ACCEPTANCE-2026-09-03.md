## Delivered slice

The desktop Activity drawer is now a first-class Team Activity surface. When a Team Channel is selected, the drawer is locked to that Team and channel; otherwise it offers a safe managed-Team selector with a recent Team fallback. The summary shows Team, status, phase, current owner, collaboration state, parallel progress, and archived context. The bounded timeline renders deterministic newest-first event cards with time, status, owner/target, bounded reason, review decision, revision, and artifact count.

Rows use the existing TeamService collaboration ledger and public projection. The projection now carries only the opaque source `conversationId` needed for canonical channel navigation. Artifact actions open the existing Files & Artifacts surface and attention actions open the existing Attention surface; no second event log, scheduler, or authority path was added. Renderer requests are limited to opaque `teamId`/`conversationId` and a bounded limit. Dynamic event text is rendered with DOM text nodes, and stale async responses are discarded when the Team/channel context changes.

Loading, empty, archived, unavailable, and error states are represented in the Activity surface. The hidden gate uses real local TeamService transitions for direct handoff/review and parallel work/review/join, two isolated Teams, the real sandboxed preload, validated IPC, app protocol, renderer, stores, restart, and stale-response scenarios. No provider, network, OAuth, cloud, remote, packaging, deployment, or account runtime was started.
