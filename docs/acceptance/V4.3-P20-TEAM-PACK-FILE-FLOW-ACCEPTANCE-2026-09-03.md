# V4.3 P20 Team Pack Local File Flow Acceptance

Date: 2026-09-03

## Scope

P20 completes the independent Team Pack Gallery's local JSON file flow. Export now uses the native save dialog and import uses the native open dialog. Both paths reuse the existing declarative Team Pack service and governed IPC surface.

The renderer receives only a bounded result and the selected file basename. Absolute paths, credentials, provider accounts, sessions, tokens, capabilities, and other authority-bearing fields are not returned to the renderer.

## Safety boundary

- Main-process file reads and writes are capped at 64 KiB.
- Imported JSON is checked at the `team:importPack` schema boundary before the domain service runs.
- Unknown fields and recursive authority-bearing fields fail closed.
- File-system errors are sanitized before crossing the renderer boundary.
- Export filenames are sanitized and returned as basenames only.
- Existing Install, Duplicate, and custom Edit behavior remains on the existing Team Pack service/IPC path.
