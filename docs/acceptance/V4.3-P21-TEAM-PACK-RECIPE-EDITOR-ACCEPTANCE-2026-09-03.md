# V4.3 P21 Team Pack Structured Recipe Editor Acceptance

Date: 2026-09-03

## Scope

P21 replaces the independent Team Pack Gallery's custom recipe window.prompt/raw JSON edit path with a product-internal structured editor. Custom and imported recipes open in a bounded form that edits the pack name and description plus coworker names, roles, instructions, safe model profiles, channel names/kinds/instructions/playbook links, and playbook names, descriptions, ordered coworker steps, expected output, and recommended roles. The form also supports bounded add/remove operations while retaining the existing declarative recipe authority.

First-party recipes remain read-only in the Gallery. Users duplicate a first-party recipe before editing it. Save calls the existing team:editPack preload/IPC path and refreshes the Gallery only after success. Validation errors remain in the open dialog; cancel closes without writing.

## Safety boundary

- The editor is made from fixed DOM controls; it has no raw JSON textarea, prompt, evaluator, or HTML injection.
- It sends only the existing name, description, coworkers, channels, and playbooks patch to team:editPack.
- The main-process productSurfaces.editPack store remains the single recipe authority and the existing IPC schema remains the fail-closed boundary.
- Model provider/model values are exposed only as bounded opaque public identifiers supported by the Team Pack schema; no credentials, accounts, sessions, permissions, workspace paths, or external-control fields are accepted.
- Minimum/maximum collection sizes and field bounds remain enforced by the existing normalization and IPC validation.
