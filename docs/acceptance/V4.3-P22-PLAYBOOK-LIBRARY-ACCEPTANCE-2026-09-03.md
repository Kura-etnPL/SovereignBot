## Delivered

- Playbooks now have a fixed structured editor for name, description, ordered steps, stages, review points, expected output, recommended coworker roles, and recommended Skills.
- Steps, stages, and review points support bounded add, remove, and reorder actions. Save and Cancel are separate; validation errors stay in the dialog.
- Team and Channel assignment uses the existing typed Playbook service and is hidden for archived Playbooks.
- Duplicate, Archive, and Restore remain real product actions and preserve the declarative definition.
- Native JSON import/export runs through main-process Electron dialogs and bounded file IO. Renderer status exposes only the selected basename.
- Import validates the existing `sovereignbot.desktop.playbook.v1` schema and rejects authority, session, token, capability, URL, and path fields.
- Reload persistence now retains unassigned imported and duplicated Playbooks; the loader validates the persisted definition separately from lifecycle metadata.

## Real acceptance evidence
