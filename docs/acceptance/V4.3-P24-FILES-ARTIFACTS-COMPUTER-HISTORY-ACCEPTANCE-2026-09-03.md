## Scope

P24 closes the independent Product Burst path for Files & Artifacts and Computer Activity History in the local desktop shell.

- Artifacts now use an in-product bounded preview dialog instead of a renderer alert. Text and JSON previews report readable/truncated state; binary artifacts report an explicit non-previewable state; read failures are sanitized and remain in-product.
- Artifact cards retain Recent, Team, Channel, Coworker, and MIME filters, use bounded catalog queries, preserve selected filters on refresh, and support exact `sovereignbot:open-artifact` navigation/focus with a safe unavailable-artifact message.
- History, Restore-as-new-version, Revise-via-native-dialog, Open, Reveal, and source-conversation navigation remain on the existing typed preload/IPC boundary. Renderer payloads expose identifiers and display metadata, never managed or source paths.
- Computer History reuses the existing runtime audit source and `product-surface-service` allowlisted projection. No second history store or parallel log was introduced; secret/auth/session/continuity events and non-allowlisted data remain excluded.
