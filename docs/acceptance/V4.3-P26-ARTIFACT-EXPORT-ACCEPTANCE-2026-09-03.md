## Selection and scope

The follow-up audit checked the three proposed local fast-paths. Voice already had persistent language, speak-replies, and mute settings wired to the Settings UI and typed `settings:update`; Attention already had the unified Attention surface, category filters, active/all/snoozed views, snooze, retry, and dismiss. Artifact already had the unique managed store, preview, Open, Reveal, History, Restore-as-new-version, and native-dialog Revise paths, but no user-controlled local export copy.

P26 adds one bounded local slice:

- Files & Artifacts now exposes `Export copy / 导出副本` on every artifact card.
- The renderer sends only an opaque `artifactId` through `artifact:exportViaDialog`; the main process resolves the artifact in the existing ArtifactStore, rejects symbolic-link sources, enforces the existing 50 MiB file bound, and uses the native Save dialog.
- The exported file is a copy of the managed bytes. Cancellation performs no write, and the result returns only basename, byte count, artifact id, and version; no managed, workspace, or source path crosses the renderer boundary.
- Artifact retention/archive/delete and external sharing were not invented: the existing append-only version lineage remains authoritative, and external share still requires a later reviewed transport/authority path.
