## Renderer dialog-debt audit

The audit scanned user-facing desktop renderer code while excluding verifier/test-only code, dead code, and legitimate native file-picker/save-dialog paths. The highest-value bounded path was the Projects page's `#project-create` action in `desktop/ui/product-hubs-ui.js`, which used `window.prompt("Project name / 项目名称")` before calling the existing typed `projects.create` API.

The selected slice replaces only that Project creation prompt with a product-internal `<dialog>` and keeps the existing main-process-owned `project:create` contract unchanged: the renderer submits only `name`; trusted workspace allocation remains in `ProjectService`.

Other remaining renderer dialogs were audited but not expanded into this slice:

- Routine Run now/Restore failures use alert fallback; this needs a bounded per-card status treatment.
- The older Team Pack gallery custom-edit fallback still has a name prompt and clipboard alert, while the independent gallery already has the structured recipe editor path; reconciling the two surfaces is a separate slice.
- Command Palette routine selection uses a prompt picker and needs a bounded routine selector.
- Legacy Memory edit/delete and Data Lifecycle restore/reset use prompt/confirm; Memory has the P25 first-class editor, while delete/reset safety needs separate destructive-flow review.
- Verified Update apply confirmation is an app-restart/update boundary and remains outside this local UX task.

## Scope and behavior

- `New Project / 新建项目` opens a bounded form with a required, 120-character name field.
- Blank/whitespace names keep the dialog open, show the validation error inside the form, and perform no IPC write.
- Cancel closes the dialog without writing.
- Save disables the button during the typed `projects.create` call, closes on success, refreshes the canonical Projects surface, and renders bounded errors in-dialog on failure.
- No new IPC channel, authority, provider, workspace-path input, external connection, destructive delete, or permission expansion was added.
