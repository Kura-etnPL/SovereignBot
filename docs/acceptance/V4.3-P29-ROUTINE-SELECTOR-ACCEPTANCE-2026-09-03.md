## Scope

P29 replaces the Command Palette `Run Routine` blocking `window.prompt` picker with a bounded product-internal selector. The selector loads the existing safe Routine projection, keeps archived, disabled, unavailable, and completed one-time entries visible with an explicit non-runnable state, and exposes only active, enabled, reference-valid Routines as selectable.

The renderer submits only the opaque `routineId` through the existing typed `palette:execute` path. The main-process Command Palette service continues to call the existing governed `routine-controller.runNow` → `JobController.submitJob` path. No new executor, IPC authority, provider access, or workspace authority was introduced.

Cancellation and no-selection submission perform no run. If a selected id becomes stale or forged, the existing governed service rejects it and the selector keeps the failure in the product dialog. Successful execution closes the selector and leaves the visible Command Palette status as the result surface; failures remain in-dialog.
