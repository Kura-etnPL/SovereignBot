## Scope

P30 closes the Routines card feedback slice for `Run now` and `Restore`. Both actions now report success and failure inside the corresponding Routine card, with a dismiss button. While a request is pending, the card action is disabled and repeated clicks are ignored; after failure the action is available for retry. Feedback is keyed by the opaque `routineId`, so refresh and re-render cannot attach a result to another Routine.

Run now and Restore retain the existing typed preload/IPC contracts and existing `RoutineController` / `JobController` lifecycle. Run now still creates one ordinary governed Job; Restore only reactivates the archived Routine and schedules its next occurrence. No scheduler, executor, provider, workspace authority, or new IPC authority was added. Error text is bounded, control-character sanitized, and suppresses opaque resource IDs and authority-bearing terms.

Archived, disabled, unavailable, and stale entries remain fail-closed. The renderer sends only the selected opaque `routineId` for these actions; stale or unavailable references are rejected by the existing trusted controller path and remain visible as card feedback.
