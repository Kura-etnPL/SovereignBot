## Scope

The P28 inventory identified two ordinary Team Pack Gallery entries: the embedded Product hubs gallery (`nav-product-hubs` → `renderPacks`) and the dedicated Team Packs page (`nav-team-packs` → `packs`). The embedded path was reachable and still used a custom-name `window.prompt` edit plus clipboard export. It now exposes the same structured `Edit recipe / 编辑配方` and native `Export / 导出` behavior as the dedicated page through a small event bridge.

Both entries reuse the existing structured editor, `team:editPack` typed preload/IPC path, canonical product-surface service, and native `team:exportPackViaDialog` JSON file flow. No store, service, editor, authority, clipboard, or path API was added. First-party recipes remain read-only and retain Duplicate guidance; custom/imported recipes remain editable; the existing in-dialog validation/error and Cancel-without-write behavior remains in the shared editor.
