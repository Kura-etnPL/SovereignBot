## Audit and slice

The audit covered the ordinary renderer entry, sandboxed preload, typed Search/Palette IPC, `SearchService` index, result projections/deep links, and the fixed Command Palette registry. The canonical search index already covered the eight required types (Conversations, Channels, Coworkers, Projects, Artifacts, Skills, Playbooks, and Routines), and the palette already exposed exactly seven actions: New Coworker, New Team, New Channel, Run Routine, Teach Skill, Open Computer, and Search.

The highest-value local gap was incomplete result navigation. Search results for Coworkers, Skills, Playbooks, and Routines did not open the exact ordinary target. The renderer now reuses `openDirect`, the existing Skill/Playbook editor events, and the existing Routine detail event. No new index, raw path, generic IPC, shell, provider/session/credential exposure, or execution authority was added. Exact target stores remain responsible for stale, archived, and forged-id rejection.
