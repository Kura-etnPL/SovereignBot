## Audit and slice

The audit covered the ordinary Projects entry, renderer surface, sandboxed preload, typed IPC/schema, ProjectService/store, existing tests, and hidden Electron acceptance. Project switcher, Recent Projects, Create, Archive/Restore, Backup, grouped Project contents, safe public projections, and fail-closed lifecycle behavior were already present. The highest-value local gap was that Project Export still copied JSON from the renderer clipboard even though ProjectService already produced a safe portable `sovereignbot.project-export.v1` projection.

P34 adds a bounded main-process native JSON export using the existing ProjectService projection and the established native dialog pattern. The renderer sends only an opaque `projectId`; the dialog and file write stay in the main process, return only cancellation/basename/byte count, and reject oversized output or save failures without exposing paths. Archive/Restore remains the existing reversible lifecycle; no physical delete, clean reset, overwrite restore, second Project/workspace store, migration, or deployment was added.
