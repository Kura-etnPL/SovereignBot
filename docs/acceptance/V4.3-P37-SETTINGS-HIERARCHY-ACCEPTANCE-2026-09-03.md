# V4.3 P37 Settings hierarchy acceptance

Date: 2026-09-03
Scope: Canonical Product Plan §39 Settings

P37 keeps ordinary Settings focused on product preferences and safe operational surfaces: Appearance/Language, Default Model Profile, Computer, Connected Apps, Notifications, local Backup/Export, Updates, Voice, and keyboard shortcuts. AI Providers, Trusted Workspaces, and the runtime roster remain available through the existing default-collapsed Advanced details element.

The implementation preserves the existing settings cards, IDs, renderer functions, typed preload/IPC channels, and event bindings. `ensureSettingsPreferences()` now labels the existing hierarchy through the shared English/Simplified Chinese i18n table and avoids re-wrapping cards already inside Advanced. No provider login, workspace picker, backup/restore, update staging/apply, or new settings authority was added.
