# V4.3 P40 — 本地记忆智能检索验收

日期：2026-09-03  
范围：`src/memory.js`、桌面 Memory service/IPC/UI，以及 P40 本地隐藏 Electron canary。

## 交付行为

- MemoryStore 统一执行有界、scope-aware 的字段化相关性排序：key/title 精确与前缀、短语、tags、content token、置顶和稳定时间 tie-break。
- coworker/team/project 通过 canonical scope 隔离；active 默认隐藏 forgotten/deleted，`includeForgotten` 只扩大可见状态，不改变 query、limit 或排序语义。
- query 明确限制为字符串、最多 300 字符且拒绝控制字符；limit 为 1–100 的整数。
- Memory 页面显示返回匹配数，并以 `Match: … / …` 显示白名单化双语命中原因；renderer 不接触 score、路径、provider、session、credential 或其它 authority 字段。
- P40 focused test 覆盖 scope 隔离、exact/tag/phrase/content、pinned-first、forget/includeForgotten、边界和重启确定性。
