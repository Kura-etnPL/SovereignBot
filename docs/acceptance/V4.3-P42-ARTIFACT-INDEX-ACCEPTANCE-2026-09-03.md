## Delivered behavior

- The canonical `artifacts.json` state is loaded once and indexed in process by ID, family, conversation, coworker, MIME type, publication, visibility, and stable append order.
- `ArtifactStore` ID/family operations and list/history/archive/restore/discard candidates use the derived index while preserving public projections and existing ordering semantics.
- `indexRecords` is an explicit bounded main-process interface with allowlisted filters, bounded identifier collections, and a maximum of 5,000 records; it is not exposed through renderer IPC.
- Artifact Hub constrains Team/Channel/Coworker candidates through the index before selecting the latest family version.
- Search indexes all published canonical artifacts up to the store bound and retains lazy construction plus existing invalidation behavior.
