## Delivered behavior

- Search derives a bounded in-memory candidate index from the canonical Search records during the existing index build.
- Non-empty queries build a normalized Unicode gram index, intersect all grams for each query token, require candidates to cover at least `ceil(queryTokens/2)` token sets, then reuse the existing `matchFor` scorer and ordering semantics.
- Empty queries retain the existing bounded enumeration behavior; invalidation and service restart rebuild the derived query index.
- Candidate/refinement counters are available only through a main-process internal diagnostic and are absent from renderer/public Search results.
- The real P43 gate seeds 5,000 canonical Artifact metadata records plus the existing mixed Search corpus, verifies a deep result through Electron Search UI/IPC, archive/restore, and restart rebuild.
