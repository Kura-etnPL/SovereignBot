## Delivered design

- Conversation Search indexes the canonical retained message history, not only the latest preview. The existing bounded store retains at most 256 conversations and 5,000 messages per conversation.
- Full-history stores expose bounded internal message records. Conversation summaries index title and metadata only when full message records are available; message records own content matches and return an opaque `messageId` plus a bounded safe snippet. Stores without `searchRecords()` retain the legacy `lastMessage` preview fallback.
- Search uses a Unicode-aware bounded candidate index before relevance scoring. Public results strip internal search text, project membership, tags, message text, provider/session data, and other authority or sensitive fields.
- Search invalidation is generation-safe. In-flight index promises carry their generation; stale completions cannot clear or overwrite a newer promise or index. Queries retry until the returned index is at least the generation observed by the query.
- Conversation navigation supports a bounded `aroundMessageId` page. Foreign or stale anchors fail closed. Search result navigation opens the conversation, loads the bounded page, and highlights the historical message.
- The gate records observer-generation evidence, full-history search, safe projection, candidate statistics, bounded anchoring, UI highlighting, fresh-message invalidation, and restart rebuild behavior. Timeout diagnostics include the last actual query result and current generation state.
