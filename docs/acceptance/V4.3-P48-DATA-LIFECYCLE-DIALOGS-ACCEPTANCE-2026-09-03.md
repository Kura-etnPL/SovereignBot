## Initial gate attempt and correction

The first Sol gate attempt was not accepted. Its functional paths were otherwise
passing, but two verifier defects invalidated the result:

1. The public-UI leak assertion rejected the ordinary UI word `confirmation`, so
   the legitimate copy “The confirmation button…” was reported as a false leak.
2. When a check failed, the gate destroyed its only BrowserWindow in `finally` before
   emitting the failure result. Electron could therefore exit with code `0` before
   the later throw/app-exit path took effect.

Verifier correction `3e0f2d0` narrowed the assertion to the exact fixture path and
opaque canaries (`confirmation=fixture` / `nonce=fixture`) and makes the gate write
evidence before explicitly selecting `app.exit(1)` for any failed check or
`app.exit(0)` only when all checks pass. The initial result is not treated as
acceptance evidence; the corrected rerun is authoritative.
