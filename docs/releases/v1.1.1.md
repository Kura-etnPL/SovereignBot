# SovereignBot 1.1.1

SovereignBot Core 1.1.1 ships together with Desktop v1.1.1 as one corrective release tree. It contains the core-side foundation the corrected Desktop depends on:

- **Trusted task-scoped execution context.** Public `submit`/`delegate` strip any smuggled execution context; only the new internal-only `orchestrator.delegateTrusted(parentId, spec, trustedContext, actor)` stamps a strictly validated `{workspaceId, cwd}` after delegation. Harness runs receive it, Codex/Claude child processes launch inside the trusted workspace (`--cd` for Codex), and every public projection strips the internal field.
- **No behavior changes to released policy semantics.** Fail-closed policy, task-bound governed computer authority, repeat guard, hash-chained audit, provider-session continuity and redaction are unchanged from v1.0.0.

The user-facing corrective scope — real Codex/Claude execution in Desktop normal mode, trusted workspace binding, independent model review, model synthesis, fake-provider installed E2E canaries, and provenance-bound publication — is documented in `docs/releases/desktop-v1.1.1.md`.

`desktop-v1.1.0` remains published and immutable; nothing was rewritten to retrofit it.
