# SovereignBot 3.0.0

SovereignBot 3.0.0 is the Windows GA baseline for the V3 Coworker Desktop: bilingual UI, Windows launcher shortcuts, keyboard access, a hardened internal-Node packaging path, and a unified `3.0.0` version identity across Core and Desktop.

This commit freezes the V3 product line. `desktop-v1.1.1` / `v1.1.1` remain published and immutable. V4 Always-On work (persistent Jobs, Routines, Attention, Teach, Event Triggers, Worker Node, Remote) starts from this commit on `feature/v4-always-on-team` without writing back to V3.

- **Internal-Node packaging:** `resources/node/node.exe v22.23.2 (sha 0d0f5e39…)` is the stable Forge path via `desktop/scripts/run-forge-with-internal-node.mjs`; host Node v24 is not used for packaging.
- **Trusted execution unchanged:** public surfaces still cannot forge `{workspaceId,cwd}`; only `delegateTrusted` does. Policy, audit, computer authority, and secret handling are unchanged.
