# SovereignBot 4.0.0

SovereignBot 4.0.0 freezes the V4 Always-On product line at one stable SemVer across Core, Desktop, runtime health, and the vendored Core payload.

## Release boundary

- Persistent Jobs, supervision, routines, event triggers, worker-node controls, and Attention remain governed by the existing policy/audit/computer boundary.
- Desktop data lifecycle migration from V3 to V4 is idempotent and creates a pre-migration backup before committing the new marker. Backup, restore, reset, and redacted export preserve protected credentials, browser, computer, and controller state.
- Windows release packaging uses Electron Forge/Squirrel and the existing fuse gate. Stable signing is fail-closed and receives certificate material only through environment-injected signer configuration.
- Updates default to the stable channel, require verified local metadata and artifact hashes, create a P6 pre-update backup, and apply only after an explicit restart action.

## Verification

Run `npm run release-version` from `desktop`, then `npm run check`, `npm test`, and the Windows-only Forge/fuse/package/installer gates when the pinned local toolchain is available. Local unsigned RC output is explicitly marked unsigned; Authenticode verification is a separate gate and is SKIP when no certificate or `signtool.exe` is present.
